- `--tls`: "Enable tls." (default false)
- `--tls_cert_file`: "Cert file(public key) for tls connections."
- `--tls_key_file`: "Private Key file for tls connections."
- `--tls_ca_cert_file`: "Certified authority signed certificate to validate tls connections."
- `--no_tls_on_admin_port`: "Allow non-tls connections on admin port." (default false)
- `--requirepass`: "Password for AUTH authentication." (default "")

Whether the CA file makes client certificates mandatory: not stated on the page.
