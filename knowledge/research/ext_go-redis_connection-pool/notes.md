# go-redis connection pool

Facts about the go-redis v9 connection pool (total cap, wait queue, pool timeout, idle eviction). Not this product’s SimpleRedis. Pin: [redis/go-redis@7f3b3df](https://github.com/redis/go-redis/tree/7f3b3dffde59329db9fa7a71d650ef373affb599) (`v9.23.0-beta.1`, default-branch HEAD on 2026-09-11). SimpleRedis must copy the **shape** with stdlib only (Yaegi-safe). Do not import go-redis.

## PoolSize caps in-use turns, not idle

`Get` takes a **pool turn** from a buffered-channel semaphore sized to `PoolSize` before it pops idle or dials. Idle sockets do **not** hold a turn. `PoolSize` is therefore the cap on concurrent in-use Gets (and in-flight dials that already hold a turn), not the idle-list length. After the turn, `Get` pops a healthy idle conn or dials. `Put` returns the socket to idle (or closes it) and **releases** the turn. ([go-redis@7f3b3df:internal/pool/pool.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool.go), [.sources/pool.go.md](.sources/pool.go.md); [go-redis@7f3b3df:internal/semaphore.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/semaphore.go), [.sources/semaphore.go.md](.sources/semaphore.go.md))

Default `PoolSize` is `10 * runtime.GOMAXPROCS(0)` when the option is `0`. Cluster options use `5 * GOMAXPROCS` per node — not this finding’s default. ([go-redis@7f3b3df:options.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/options.go), [.sources/options.go.md](.sources/options.go.md); [Debugging Go Redis](https://redis.uptrace.dev/guide/go-redis-debugging.html), [.sources/go-redis-debugging.md](.sources/go-redis-debugging.md))

**Conflict (godoc vs pool):** `Options.PoolSize` godoc still says it is a “base number” and that new sockets “will be allocated in excess of PoolSize”, limited by `MaxActiveConns`. On this pin, `Get` cannot proceed without a `PoolSize` turn. Excess dials that sneak through are marked `pooled=false` and closed on `Put`. Follow **source** (`FastSemaphore(PoolSize)` + `waitTurn`). The generic Redis pools page that says a full pool “simply open[s] new connections” is the same stale shape. ([options.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/options.go), [.sources/options.go.md](.sources/options.go.md); [Connection pools and multiplexing](https://redis.io/docs/latest/develop/clients/pools-and-muxing/), [.sources/pools-and-muxing.md](.sources/pools-and-muxing.md))

`MaxActiveConns` (default `0` = unlimited) is a **second**, fail-fast ceiling in `newConn`: at or above it, `Get` returns `redis: connection pool exhausted` (`ErrPoolExhausted`) instead of waiting. ([pool.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool.go), [.sources/pool.go.md](.sources/pool.go.md))

## Waiters block; PoolTimeout returns ErrPoolTimeout

When every turn is taken, `waitTurn` blocks on `FastSemaphore.Acquire(ctx, PoolTimeout, ErrPoolTimeout)`. The wait is a `select` on the token channel, the caller context, and a timer. Timeout returns `pool.ErrPoolTimeout` (`"redis: connection pool timeout"`), re-exported as `redis.ErrPoolTimeout`. `Get` increments `Stats.Timeouts`. A cancelled context returns `ctx.Err()`, not the pool timeout. `TryGet` does not wait: it returns `ErrPoolTryFull` (`"redis: connection pool has no free turn"`). ([pool.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool.go), [.sources/pool.go.md](.sources/pool.go.md); [semaphore.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/semaphore.go), [.sources/semaphore.go.md](.sources/semaphore.go.md); [error.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/error.go), [.sources/error.go.md](.sources/error.go.md); [Debugging Go Redis](https://redis.uptrace.dev/guide/go-redis-debugging.html), [.sources/go-redis-debugging.md](.sources/go-redis-debugging.md); [pool_test.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool_test.go), [.sources/pool_test.go.md](.sources/pool_test.go.md))

Default `PoolTimeout` when the option is `0`: `ReadTimeout + 1s` if `ReadTimeout > 0`, else `30s`. On this pin, default `ReadTimeout` is **5s**, so default `PoolTimeout` is **6s**. ([options.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/options.go), [.sources/options.go.md](.sources/options.go.md))

**Conflict (official prod docs vs this pin):** Redis “Production usage” still says default read/write timeout is **three** seconds. Follow **source** for `7f3b3df` (`ReadTimeout` `0` → 5s). That also moves default `PoolTimeout` from the older 4s (`3s+1s`) to **6s**. ([Production usage](https://redis.io/docs/latest/develop/clients/go/produsage/), [.sources/produsage.md](.sources/produsage.md))

## Idle overflow closes under PoolSize when MaxIdleConns is set

Default `MaxIdleConns` is `0`, and `Put` treats `0` as **no idle cap**: idle sockets are not closed for count. Idle can then hold every pooled socket, up to `PoolSize`. ([options.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/options.go), [.sources/options.go.md](.sources/options.go.md); [pool.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool.go), [.sources/pool.go.md](.sources/pool.go.md))

When `MaxIdleConns > 0` and `idleConnsLen >= MaxIdleConns`, `Put` **closes** the socket (`errConnEvictedIdle`), even if `poolSize` is still below `PoolSize`. Test: `PoolSize=2`, `MaxIdleConns=1` — second `Put` evicts. ([pool.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/pool.go), [.sources/pool.go.md](.sources/pool.go.md); [hooks_test.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/internal/pool/hooks_test.go), [.sources/hooks_test.go.md](.sources/hooks_test.go.md))

Stale idle is a different closer: `ConnMaxIdleTime` default **30 minutes**, checked lazily on the next `Get` (`isHealthyConn`). ([options.go](https://github.com/redis/go-redis/blob/7f3b3dffde59329db9fa7a71d650ef373affb599/options.go), [.sources/options.go.md](.sources/options.go.md))
